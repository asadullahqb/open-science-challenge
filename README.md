# EY Open Science AI Data Challenge 2025 — Urban Heat Islands

Independent submission to the EY Open Science AI Data Challenge 2025 (Urban Heat Islands track). Contains notebooks, feature engineering, and model pipelines developed to predict urban heat island intensity from geospatial and weather data.

## Contents
- `Solo Model/`, `AI Men/`, `Golden/`, `Sample/`, `ZeRo/` — experiment iterations (notebooks, pipelines, and submissions).

## Tech
Python, Jupyter, geospatial libraries (Geopandas/Rasterio), XGBoost, genetic-algorithm feature selection.

## Note
Large raster and geodatabase files (>50 MB) were excluded from this repository.
